# Pi Ecosystem Site

A static HTML website for the Pi Ecosystem, served by a simple Python HTTP server.

## Stack

- **Runtime:** Python 3.12 (stdlib `http.server`)
- **Pages:** `index.html`, `logic.html`, `pinet.html`, `wallet.html`
- **Assets:** Images and a loading GIF in the root and `assets/` directory

## How to run

The workflow `Start application` runs:

```
python server.py
```

This serves all static files on port 5000 with no-cache headers. No dependencies to install.
